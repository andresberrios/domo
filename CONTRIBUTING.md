# Contributing to Domo

Thanks for your interest in contributing. Issues and pull requests are welcome.

## Getting started

- Read [`docs/project-context.md`](docs/project-context.md) and [`docs/initial-design.md`](docs/initial-design.md) for what Domo is and how it's built.
- Dev setup is in the [README](README.md#develop-from-source). Run `pnpm typecheck` and `pnpm lint` before opening a PR.
- Keep `docs/` and `CLAUDE.md` in sync in the same change when you touch something they describe.

## Developer Certificate of Origin (sign-off required)

Every commit must be signed off, certifying you wrote the contribution or otherwise have the right to submit it under this project's license:

```bash
git commit -s -m "your message"
```

This appends a `Signed-off-by: Your Name <you@example.com>` line, which asserts the Developer Certificate of Origin 1.1 (full text below). PRs whose commits are not signed off cannot be merged.
